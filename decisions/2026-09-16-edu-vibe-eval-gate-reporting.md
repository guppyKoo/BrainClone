# 결정: Gate 결과는 기록하되 품질 집계와 그래프에서 분리한다

이 결정은 [[2026-09-15-edu-vibe-llm-eval-pipeline]]의 `ZERO_SCORED` 집계 정책을 대체한다.

## 배경

현재 Gate는 응답 완료·정책 차단·HTML 존재와 실행 가능성만 검사했다. 그래서 `hi`, `알아서 해줘`처럼
검증 가능한 요구 `R`이 없는 발화도 AI가 HTML을 생성하면 `COMPLETED`가 됐다. 이 경우 `S=0`,
`Q1=null`이면서 Q2·Q3만 그래프에 포함돼 품질 모집단의 의미가 흐려진다.

실행 불가 HTML도 Q1~Q3를 0점으로 기록해 두는 것은 필요하지만, 브라우저 평가를 끝까지 수행한
정상 턴과 같은 그래프에 넣으면 생성 품질과 Gate 실패율이 섞인다.

## 결정

- R 추출 뒤 `requirements=[]`이면 `NO_TESTABLE_REQUIREMENT`로 Gate 제외한다.
- `SKIPPED`와 실행 불가 `ZERO_SCORED`는 원인과 점수를 저장한다.
- 평균과 S/L별 모든 그래프에는 Gate 결과가 `ELIGIBLE`인 완료 턴만 포함한다.
- Gate에서 제외되거나 0점을 받은 턴은 보고서의 별도 목록에서 turnId, 분류, 원인, 점수와 원문
  대화를 추적한다.
- 같은 출력 경로로 재실행할 때 한 턴의 최종 상태 파일은 하나만 남긴다.

## 기각한 대안

- **R이 없는 턴을 `S=0` 품질 표본으로 유지**: Q1을 정의할 수 없고 AI가 임의로 만든 결과를 어떤
  요구에 대해 채점하는지 설명할 수 없어 기각했다.
- **실행 불가 0점을 정상 품질 그래프에 포함**: Gate 실패율과 정상 실행된 결과의 Q 분포를 한 축에
  섞으므로 기각했다. 0점 기록 자체는 삭제하지 않고 별도 목록으로 보존한다.
- **Gate 결과를 보고서에서 숨김**: 제외 규모와 원인을 추적할 수 없으므로 기각했다.

## 대체 관계

[[2026-09-15-edu-vibe-llm-eval-pipeline]]의 “`ZERO_SCORED`를 Q1~Q3 0점으로 집계한다”는 결정 중
**그래프와 평균 집계에 포함하는 부분만** 이 문서가 대체한다. 실행 불가 결과를 0점으로 기록하는
정책은 유지한다.
