# 결정: Q1~Q4·L·S와 두 종류의 모호함을 독립 관측한다

이 결정은 [[2026-09-11-edu-vibe-llm-evaluation]]의 이론 설계에서 **종합 Q·과제별 계약·개선 판단을
현재 단계의 범위 밖으로 내보내고**, 하나의 사용자 발화와 그에 대한 하나의 답변을 독립적으로 관측하는
모델로 좁힌다.

지금의 목적은 점수 하나로 품질을 결론내리거나 배포를 막는 것이 아니다. 발화와 결과에서 원자료를
일관되게 추출해, 나중에 조건별 분포와 관계를 분석할 수 있게 만드는 것이다.

## 관측값

| 값 | 의미 | 정보 경계 |
|---|---|---|
| `S` | 현재 발화의 명세량 | 현재 발화 |
| `L` | 현재 발화가 요구하는 작업의 난이도 | 현재 발화 |
| `Q1` | 현재 발화에 명시된 요구의 충족도 | 현재 발화 + 해당 답변·결과물 |
| `Q2` | 답변이 기존 결과물을 보존한 정도 | 답변 전·후 작업물 (이전 결과물이 없으면 `null`) |
| `Q3` | 현재 발화가 요구한 범위만 변경한 정도 | 현재 발화 + 답변 전·후 작업물 |
| `Q4` | 생성한 코드·설명의 학습 적합성 | 해당 답변·결과물 |
| `utteranceAmbiguity` | 현재 발화 자체가 모호한 정도 | **현재 발화만** |
| `contextualAmbiguity` | 실제 생성 맥락까지 보아도 남는 모호함 | 현재 발화 + 대화 기록 + 현재 작업물·화면 |

`utteranceAmbiguity`와 `contextualAmbiguity`는 서로 대체하지 않는다. 예를 들어 `"그거 빨간색으로"`는
문장만 보면 모호하지만 화면에서 대상이 선택돼 있다면 전자는 높고 후자는 낮을 수 있다.

## 평가 원칙

- Q1~Q4는 후속 발화로 이전 턴을 소급 평가하지 않는다.
- Q1은 사용자가 **현재 발화에서 명시한 것만** 검사한다. 말하지 않은 위치·색·대상은 Q1 감점 사유가 아니다.
- 요청하지 않은 변경은 Q1이 아니라 Q3에서 다룬다.
- 종합 Q와 Q1~Q4 가중합을 만들지 않는다.
- `S`, `L`, 두 ambiguity 값도 Q에 더하거나 빼지 않고 조건·필터 값으로만 쓴다.
- 주관적 요구는 객관적 진리로 가장하지 않는다. 고정된 judge의 선호 또는 사람 집단의 선호 분포임을 함께 기록한다.
- LLM은 비정형 발화·결과에서 구조화된 관측값을 추출한다. 프로그램으로 검증 가능한 조건은 브라우저·DOM·style·동작 검사 결과를 알고리즘이 집계한다.

## 출력 단계와 판단 단계의 분리

현재 단계의 출력은 Q1~Q4 각각에 대한 `S`, `L`, `(S,L)` 조건별 분포이며, 두 ambiguity 값으로
필터링하거나 나란히 비교할 수 있다. 여기서 어떤 프롬프트·모델·컨텍스트 구성을 바꿀지는 이후 단계다.

## 기각·보류한 것

- 과제별 정답 계약을 사람이 또는 LLM이 등록하는 구조
- 모든 자연어 요구를 미리 정의된 동작별 분기로 망라하는 구조
- 종합 품질 점수와 축별 가중치
- 현재 수집 단계에서 곧바로 회귀·배포 게이트로 사용하는 것
