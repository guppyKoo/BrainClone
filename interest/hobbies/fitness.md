# 운동 루틴

## 현재

- **주 6일 헬스** 루틴을 유지하고 있다
- 인바디 측정값을 기준으로 운동과 식단을 계획한다 — 목표는 체지방 감소와 상체 근육 증가
- 데이터 기반으로 계획하고 루틴을 체계화하는 방식 — 개발할 때와 같은 스타일이다 ([[tendency]])

> 세부 수치와 식단 목표는 사용자가 직접 관리한다. 이 문서는 루틴의 존재와 방향만 기록한다.
