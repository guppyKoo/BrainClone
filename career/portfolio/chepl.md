# ChePL — 체육대회 운영 통합 플랫폼

2024년 3월부터 4월까지 개발한 학교 체육대회 운영 시스템이다. 학교 웹메일 인증을 기반으로 사용자와 경기 운영 데이터를 통합 관리했다.

## 기술 스택

- React
- Firebase Authentication
- Recoil
- TailwindCSS
- Firebase Hosting

## 주요 역할과 성과

- Firebase Authentication으로 학교 웹메일 기반 실명 인증과 사용자 관리를 구현했다.
- 사용자·팀 ID를 기준으로 독립적인 쿼리 키를 관리해 사용자·팀별 데이터를 분리했다.
- Firebase의 onSnapshot을 활용해 경기 데이터를 실시간으로 반영했다.
- Recoil 기반 상태 분리와 캐싱 전략으로 로그인 및 운영진 상태 관리를 최적화했다.
- 운영진의 사용성을 고려한 반응형 인터페이스를 TailwindCSS로 설계했다.
- 랜덤 대진표 생성 알고리즘을 모듈화해 여러 종목에서 재사용할 수 있게 했다.
- Firebase Hosting으로 서비스를 배포하고 관리했다.
