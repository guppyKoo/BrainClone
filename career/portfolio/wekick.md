# WeKick — 교내 풋살 매칭 플랫폼

2025년 1월부터 진행한 교내 풋살 웹 플랫폼이다. 실시간 경기 매칭, 경기 기록과 사용자 관리 기능을 제공한다. 기획과 프론트엔드 개발을 주도했고, 수업 프로젝트에서 멈추지 않고 실제 사업자 등록까지 마친 뒤 실 스폰서를 유치했다.

## 기술 스택

- Next.js
- React
- TypeScript
- TailwindCSS
- Firebase

## 제품 & 담당 역할

- 학교 웹메일 인증 기반 사용자 시스템과 경기 기록 관리 시스템을 설계했다.
- Atomic Design 패턴을 적용해 컴포넌트의 재사용성과 유지보수성을 높였다.
- 모바일 환경에 최적화된 반응형 UI와 UX를 설계하고 구현했다.
- 운영진 전용 어드민 페이지에서 경기 관리와 데이터 통제 기능을 제공했다.
- 검색 조건에 따른 실시간 필터링으로 사용자 탐색 편의성을 높였다.
- Figma를 바탕으로 화면을 기획하고 API 명세서를 작성해 프론트엔드와 백엔드의 협업 기준을 맞췄다.
- 역할 기반 접근 제어를 구현하고 사용자 피드백을 반영해 UX를 반복 개선했다.
- 프로젝트를 고립된 코딩 과제로 다루지 않고 제품 기획과 프론트엔드 개발을 넘나들며 일했다.

## 성과 & 배운 것

- 사업자 등록 후 3개 기업으로부터 스폰서십을 확보했다.
- 서비스는 충분한 리텐션을 만들지 못했고, 지속되는 제품으로는 결국 실패했다.
- 대신 제품 검증, 운영, 스폰서십, 사용자 피드백, 그리고 "서비스를 출시하는 것"과 "사용자를 붙잡는 것"의 차이를 실전으로 경험했다.
