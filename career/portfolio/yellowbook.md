# Yellowbook — 소상공인 재고·일정 관리 플랫폼

2024년 3월부터 4월까지 개발한 소상공인 팀 대상 B2B SaaS 웹 서비스다. 재고와 발주 일정을 팀 단위로 관리할 수 있도록 구축했다.

## 기술 스택

- React
- TanStack Query
- Recoil
- TailwindCSS
- Styled-Components
- react-calendar
- dayjs
- Framer Motion

## 주요 역할과 성과

- 팀 ID를 기준으로 쿼리 키를 독립적으로 관리해 팀별 데이터를 분리했다.
- 로그인 사용자의 판매자·생산자·직원 권한에 따라 라우팅과 기능 접근을 동적으로 분기했다.
- react-calendar와 dayjs를 활용해 팀별 발주 일정 관리 기능을 구현했다.
- Framer Motion으로 페이지 전환과 모달 진입 애니메이션을 구현했다.
- Figma를 바탕으로 화면을 기획하고 API 명세서를 작성해 프론트엔드와 백엔드의 협업 기준을 맞췄다.
