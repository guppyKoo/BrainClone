# Re:Bid — 입찰 기반 업사이클링 중고 거래 플랫폼

2024년 5월 개발한 업사이클링 제품 중고 거래 웹 서비스다. 사용자가 제품에 실시간으로 입찰하고 낙찰 결과를 확인하는 흐름을 구현했다.

## 기술 스택

- React
- Recoil
- Axios
- TailwindCSS
- DaisyUI
- react-cookie
- React Hook Form

## 주요 역할과 성과

- JWT 기반 인증 시스템을 구축하고 react-cookie로 인증 상태를 관리했다.
- 주기적 polling으로 입찰 가격을 갱신하는 실시간 입찰 흐름을 구현했다.
- Recoil로 입찰 상태와 사용자 상태를 전역에서 통합 관리했다.
- TailwindCSS와 DaisyUI를 조합해 모바일과 데스크톱에 대응하는 반응형 UI를 설계했다.
- React Hook Form으로 입찰 가격 유효성 검증을 구현해 입력 UX를 개선했다.
- 낙찰 처리와 입찰 실패를 포함한 여러 사용자 시나리오의 예외 처리를 강화했다.
- Figma를 바탕으로 화면을 기획하고 API 명세서를 작성해 프론트엔드와 백엔드의 협업 기준을 맞췄다.
